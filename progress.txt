## Session Notes (2026-05-27) — iOS networking layer (US-169)
Wired the iOS app to the same Supabase project + Hono edge service the web
uses. No parallel backend.

What landed:
- ios/project.yml — Supabase SPM package pinned to 2.x; xcconfig references
  for Debug + Release.
- ios/GradeThread/Config/{Debug,Release}.xcconfig — SUPABASE_URL,
  SUPABASE_ANON_KEY, EDGE_API_URL with placeholder values. The // in URLs
  is escaped as /$()/ so xcconfig's comment parser doesn't choke on it.
- ios/GradeThread/Info.plist — surfaces those three keys via $(VAR)
  substitution.
- ios/GradeThread/Networking/AppConfig.swift — runtime accessor; fatalError
  on missing/placeholder values so a misconfigured build crashes loudly at
  startup instead of silently sending requests nowhere.
- ios/GradeThread/Networking/SupabaseShared.swift — one shared SupabaseClient
  + currentAccessToken() that returns nil instead of throwing when no
  session exists.
- ios/GradeThread/Networking/EdgeAPI.swift — actor wrapping URLSession.
  getJSON / postJSON / deleteJSON; auto-attaches Bearer token; snake_case
  + ISO8601 to match the edge service.
- ios/GradeThread/Networking/EdgeAPIError.swift — typed error enum;
  parses the edge service's { error, detail } JSON into structured cases.
- ios/GradeThreadTests/EdgeAPITests.swift — hermetic tests with a custom
  URLProtocol mock. Covers: auth-header attachment, body encoding,
  nil-token-omits-header, 401→.unauthorized, 429→.rateLimited, 400→
  .badRequest(detail), 500→.serverError(detail), network failure→
  .network. No real HTTP.

Compilation runs in CI on macOS — local Windows shell can't verify Swift
syntax, so first CI run after merge is the real check.
