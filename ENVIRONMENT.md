# GradeThread + FlipDesk — Environment Variables

This documents every environment variable the app actually reads, where it
goes, and where to obtain it. Generated by scanning the codebase
(`Deno.env.get(...)` in the edge service, `import.meta.env.VITE_*` in the
frontend), so it reflects current usage — not just the `.env.example` files.

There are **two places** env vars live:

| Target | What runs there | How to set vars |
|---|---|---|
| **Frontend build** (Cloudflare Pages) | The React SPA | Build-time env vars in Cloudflare Pages → Settings → Environment variables. Only `VITE_*` vars are exposed to the browser. |
| **Edge function service** (Coolify) | The Deno/Hono API at `functions.gradethread.com` | Service env vars in Coolify → your service → Environment Variables. These are server-side secrets — never prefix with `VITE_`. |

> Self-hosted Supabase has its own infrastructure `.env` (GoTrue, Postgres,
> Storage, etc.). That is **not** covered here — this doc is only the
> application-level vars for the frontend and the edge service.

---

## 1. Frontend (Cloudflare Pages build)

| Variable | Required | Purpose | Where to get it |
|---|---|---|---|
| `VITE_SUPABASE_URL` | ✅ Required | Supabase API base URL | Your self-hosted Supabase: `https://api.gradethread.com` |
| `VITE_SUPABASE_ANON_KEY` | ✅ Required | Public anon key for client-side auth/queries (RLS-protected) | Supabase → Settings → API → `anon` `public` key |
| `VITE_STRIPE_PUBLISHABLE_KEY` | ✅ Required (for billing) | Stripe.js publishable key | Stripe Dashboard → Developers → API keys → Publishable key (`pk_...`) |
| `VITE_EDGE_API_URL` | ✅ Required | Base URL of the edge function service. **Distinct from `VITE_SUPABASE_URL`** — Supabase Kong runs on `api.*`, the Hono edge service runs on `functions.*`. | `https://functions.gradethread.com` |
| `VITE_SENTRY_DSN` | ⬜ Optional | Frontend error reporting; disabled if blank | Sentry → Project → Settings → Client Keys (DSN) |
| `VITE_POSTHOG_KEY` | ⬜ Optional | Product analytics; disabled if blank | PostHog → Project Settings → Project API Key |
| `VITE_POSTHOG_HOST` | ⬜ Optional | PostHog ingestion host | `https://us.i.posthog.com` (or your region/self-hosted host) |

Notes:
- Everything in this list ships to the browser. **Never** put secret keys here.
- `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` are mandatory — the Supabase
  client throws on startup if either is missing.

## 2. Edge function service (Coolify) — server-side secrets

### 2a. Core / Supabase

| Variable | Required | Purpose | Where to get it |
|---|---|---|---|
| `SUPABASE_URL` | ✅ Required | Supabase API base URL (server side) | `https://api.gradethread.com` |
| `SUPABASE_SERVICE_ROLE_KEY` | ✅ Required | Service-role key — bypasses RLS for grading, webhooks, admin writes | Supabase → Settings → API → `service_role` key |
| `SUPABASE_SERVICE_KEY` | ⬜ Optional | Legacy fallback name; only used if `SUPABASE_SERVICE_ROLE_KEY` is unset | Same value as above — prefer setting `SUPABASE_SERVICE_ROLE_KEY` |
| `PORT` | ⬜ Optional | Port the Hono server binds | Defaults to `8787` |
| `SITE_URL` | ✅ Required (for billing) | Used to build Stripe checkout success/cancel return URLs | Your frontend URL, e.g. `https://gradethread.com` |
| `EDGE_ENV` | ✅ Required (prod) | Deploy environment. **Defaults to `production` when unset (fail-closed).** When `production`, all security debug flags (e.g. `WEBHOOK_PAYOUT_DEBUG`) are ignored and signature verification can never be bypassed. Set to `development` only in local dev. | `production` in Coolify; `development` in `docker-compose.dev.yml` |

### 2b. AI — Anthropic (Claude)

These are wired through `services/edge-functions/src/lib/ai-config.ts` and are
designed to be set once as **Coolify Team Shared Variables** so every Pearson
Media project flips together when a model or timeout changes.

| Variable | Required | Purpose | Where to get it |
|---|---|---|---|
| `ANTHROPIC_API_KEY` | ✅ Required* | Anthropic API key — powers grading + item enrichment + listing copy | [console.anthropic.com](https://console.anthropic.com) → API Keys (`sk-ant-...`) |
| `CLAUDE_API_KEY` | ⬜ Alias | Fallback name read if `ANTHROPIC_API_KEY` is unset. Set either one. | Same value as above |
| `DEFAULT_AI_MODEL` | ⬜ Optional | Vision-capable model used for grading + composite + any photo-bearing extract call. Default: `claude-sonnet-4-6` | Anthropic model ID |
| `LIGHTWEIGHT_AI_MODEL` | ⬜ Optional | Cheap text-only model used for enrichment / listing copy when no photos are attached. Default: `claude-haiku-4-5-20251001` | Anthropic model ID |
| `AI_TIMEOUT_MS` | ⬜ Optional | SDK request timeout. Default: `120000` (2 min) | — |
| `AI_MAX_RETRIES` | ⬜ Optional | SDK retry count on transient failures. Default: `2` | — |
| `AI_TEMPERATURE` | ⬜ Optional | Sampling temperature (0–1). Unset → SDK default | — |
| `AI_ENABLE_CACHING` | ⬜ Optional | Toggle Anthropic prompt caching on system prompts. Default: `true` | — |
| `AI_DEFAULT_PROVIDER` | ⬜ Reserved | Provider selector for future multi-provider routing. GradeThread's edge service currently always uses Anthropic. | — |
| `OPENAI_GLOBAL_API` | ⬜ Reserved | OpenAI key — reserved for future multi-provider routing; not read today | — |
| `GOOGLE_GLOBAL_API` | ⬜ Reserved | Google AI key — reserved for future multi-provider routing; not read today | — |

\* Required in the sense that *one of* `ANTHROPIC_API_KEY` or `CLAUDE_API_KEY`
must be set. The grading + extract code raises on first AI call if neither is
present.

### 2c. Stripe (payments & subscriptions)

| Variable | Required | Purpose | Where to get it |
|---|---|---|---|
| `STRIPE_SECRET_KEY` | ✅ Required (for billing) | Server-side Stripe API key | Stripe → Developers → API keys → Secret key (`sk_...`) |
| `STRIPE_WEBHOOK_SECRET` | ✅ Required (for billing) | Verifies incoming Stripe webhook signatures | Stripe → Developers → Webhooks → your endpoint → Signing secret (`whsec_...`) |
| `STRIPE_PRICE_STARTER_MONTHLY` | ✅ Required (for billing) | Price ID for the Starter plan checkout | Stripe → Products → Starter plan → Pricing → API ID (`price_...`) |
| `STRIPE_PRICE_PROFESSIONAL_MONTHLY` | ✅ Required (for billing) | Price ID for the Professional plan checkout | Stripe → Products → Professional plan → Pricing → API ID (`price_...`) |

Point the Stripe webhook endpoint at `https://functions.gradethread.com/api/webhooks/stripe`
(the edge service host — `api.*` is Supabase Kong and will 404 this path).
Confirm the exact path in `services/edge-functions/src/main.ts`.

### 2d. Email — Resend

| Variable | Required | Purpose | Where to get it |
|---|---|---|---|
| `RESEND_API_KEY` | ⬜ Optional* | Transactional email (grade-complete, dispute updates, etc.) | [resend.com](https://resend.com) → API Keys (`re_...`) |

\* Email sending is skipped gracefully if unset, but notification emails won't
be delivered. Set it for production.

### 2e. eBay — FlipDesk marketplace integration

eBay endpoints are currently **stubs**. With no `EBAY_APP_ID` set they return
`503 "eBay not configured"`; with it set they return `501 "Not implemented"`
until US-119–125 are built. Set these when you build/enable the eBay flow.

| Variable | Required | Purpose | Where to get it |
|---|---|---|---|
| `EBAY_ENV` | When using eBay | `sandbox` or `production` | Your choice (`sandbox` until production access is approved) |
| `EBAY_APP_ID` | When using eBay | OAuth client ID; also gates the eBay endpoints | [developer.ebay.com](https://developer.ebay.com) → My Account → Application Keys → App ID (Client ID) |
| `EBAY_CERT_ID` | When using eBay | OAuth client secret | eBay developer keyset → Cert ID (Client Secret) |
| `EBAY_DEV_ID` | When using eBay | eBay developer account ID | eBay developer keyset → Dev ID |
| `EBAY_REDIRECT_URI` | When using eBay | OAuth callback URL (eBay calls this "RuName" target) | Must match the redirect registered in your eBay app, e.g. `https://functions.gradethread.com/api/flipdesk/ebay/oauth/callback` |
| `EBAY_VERIFICATION_TOKEN` | When using eBay notifications | Shared secret eBay sends with Notification API deliveries (incl. account-deletion) | A random string you generate, then register in eBay's Notification settings |

### 2f. Cloudflare R2 — FlipDesk photo cold storage

For US-130 (archive photos older than 30 days). **Not yet built** — set only
when that feature lands.

| Variable | Required | Purpose | Where to get it |
|---|---|---|---|
| `R2_ACCOUNT_ID` | When using R2 archival | Cloudflare account ID | Cloudflare dashboard → R2 → account ID |
| `R2_ACCESS_KEY_ID` | When using R2 archival | R2 S3-API access key | Cloudflare → R2 → Manage R2 API Tokens |
| `R2_SECRET_ACCESS_KEY` | When using R2 archival | R2 S3-API secret | Same R2 API token (shown once on creation) |
| `R2_BUCKET` | When using R2 archival | Target bucket name | Cloudflare → R2 → your bucket, e.g. `gradethread-archive` |
| `R2_PUBLIC_BASE_URL` | When using R2 archival | Public CDN base for archived photos | Your R2 custom domain, e.g. `https://cdn.gradethread.com` |

### 2g. Internal / scheduled jobs

| Variable | Required | Purpose | Where to get it |
|---|---|---|---|
| `FLIPDESK_INTERNAL_JOB_SECRET` | When using scheduled jobs | Auth token for cron → POST job endpoints (US-131, not yet built) | A random string you generate; share it with the scheduler |
| `GRADETHREAD_API_KEY` | ⬜ Optional | Only if FlipDesk runs as a *separate* frontend hitting GradeThread's public API. In the consolidated service it's unnecessary (uses the service-role client). | Generate in-app at `/dashboard/api-keys` |

### 2h. Coolify deploy

| Variable | Required | Purpose | Where to get it |
|---|---|---|---|
| `COOLIFY_FQDN` | ⬜ Optional | FQDN Traefik binds the service to | Defaults to `https://functions.gradethread.com`; see `services/edge-functions/COOLIFY.md` |

## Minimum set to run today

The features that are currently built and verified need only:

**Frontend (Cloudflare Pages):**
`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_STRIPE_PUBLISHABLE_KEY`,
`VITE_EDGE_API_URL`

**Edge service (Coolify):**
`SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `ANTHROPIC_API_KEY`,
`STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, `STRIPE_PRICE_STARTER_MONTHLY`,
`STRIPE_PRICE_PROFESSIONAL_MONTHLY`, `SITE_URL`, `RESEND_API_KEY`

Everything in sections **2e–2g** (eBay, R2, job secret) is for FlipDesk
features that are still stubbed — add them only as those stories ship.
