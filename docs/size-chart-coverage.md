Generated by `deno run --allow-read --allow-write scripts/size-chart-coverage.mjs`. Do not hand-edit; regenerate after adding charts.

Coverage is measured the way the size-guide panel resolves a chart: a real brand + garment query through `findSizingCharts`, narrowed by `categoryMatch`. A brand can hold several charts and still show a gap here, which is the point.
